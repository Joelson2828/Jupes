# Jupes Diesel — Website

## Como executar
1. Extraia a pasta ou abra `index.html` no navegador.
2. Para uma experiência mais estável, use o Live Server do VS Code.
3. O formulário abre o WhatsApp com uma mensagem pré-preenchida.
4. Atualize os dados confirmados da empresa, o horário, o ponto exato do mapa, os links das redes sociais e os produtos reais antes de publicar.

## Estrutura
- index.html
- styles.css
- script.js
- assets/logo-jupes-diesel.jpeg
- assets/*.svg

## Observações
- O website é responsivo para telemóvel, tablet e computador.
- O catálogo usa cartões ilustrativos; substitua-os por fotografias reais dos produtos.
- A localização indicada é Camama 1, conforme o briefing. A morada detalhada deve ser confirmada.
